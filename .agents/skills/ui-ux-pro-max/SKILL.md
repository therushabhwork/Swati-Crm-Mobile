# UI/UX Pro Max

Use ONLY when the task requires major, specifically requested UX changes, design research, or modern ideation. Do NOT use this skill for routine application UI implementation. 

## Activation Conditions

Use ONLY when the task is something like:
- "Design a new dashboard."
- "What's the best UX for this onboarding flow?"
- "Create a modern fintech design."
- "Give me UX recommendations."
- "Analyze this interface."

DO NOT use for routine implementation (e.g., "Add a search field", "Implement this screenshot", "Add pagination"). Do NOT use every time.
