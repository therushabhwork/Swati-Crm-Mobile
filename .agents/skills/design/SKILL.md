# Design

Activate ONLY for specific branding/marketing needs such as:
- branding
- logo
- marketing banner
- presentation / slides
- social media
- illustration
- icon design
- campaign

DO NOT activate for app UI (React Native screens, Expo screens, API forms, etc.). For app UI, use `ui-styling` + `design-system`.
Do NOT use every time.
